# Pixel Arcade

Five pixel-art mini-games in one browser hub: **Snake**, **Bricks**, **Pixel Bird**, **2048** and **5 Letters**.
Plain HTML, CSS and JavaScript. No build step, no dependencies, no backend.

- Keyboard, mouse and touch controls (swipe / tap on phones)
- Pause on `Esc` or `P`, auto-pause when the tab loses focus
- Russian and English interface
- High scores are stored locally in the browser (`localStorage`)

## 5 Letters

Guess the hidden five-letter word in six tries. Green means the letter is in the right place, yellow
means it is in the word but elsewhere, grey means it is not in the word. Every solved word adds one to
the streak and a new word starts; a missed word ends the run. The words follow the interface language:
Russian nouns or English words, no proper names.

The word lists live in `js/games/words-data.js`, generated by `tools/build-words.py`. The words the game
can pick are curated by hand in `tools/answers-ru.txt` and `tools/answers-en.txt`; the larger
dictionaries only decide which guesses are accepted.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```
python -m http.server 8000
```
