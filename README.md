# Pixel Arcade

Four pixel-art mini-games in one browser hub: **Snake**, **Bricks**, **Pixel Bird** and **2048**.
Plain HTML, CSS and JavaScript. No build step, no dependencies, no backend.

- Keyboard, mouse and touch controls (swipe / tap on phones)
- Pause on `Esc` or `P`, auto-pause when the tab loses focus
- Russian and English interface
- High scores are stored locally in the browser (`localStorage`)

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```
python -m http.server 8000
```
